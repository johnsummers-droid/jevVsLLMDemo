IF SOMETHING GOES WRONG
-----------------------
  - Every page says "Could not reach the server": open /api/health; if it
    does not answer, check the Render service status and logs.
  - "blocked by CORS policy" in the browser console: ALLOWED_ORIGINS on
    Render must be exactly https://jev-vs-llm-demo-delta.vercel.app
    (no trailing slash).
  - A team lost its browser storage: it rejoins with the SAME team name and
    gets its graph back.
  - A bad deploy: Render -> Deploys -> roll back to the previous one;
    Vercel -> Deployments -> "Instant Rollback".
